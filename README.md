## ✨ Deskripsi Singkat

Aplikasi web ini dikembangkan menggunakan *R Shiny* sebagai tugas akhir mata kuliah Komputasi Statistik.  
Tujuan utama aplikasi adalah memudahkan pengguna  baik mahasiswa, peneliti, maupun praktisi  dalam melakukan *analisis regresi linear* dengan antarmuka interaktif.  

Analisis mencakup:
1️⃣ Penentuan ukuran sampel (n) untuk berbagai metode sampling:
1. Simple Random Sampling (SRS)
2. Systematic Sampling
3. Stratified Random Sampling (Optimal Neyman)
4. Cluster Sampling dengan ICC dan Design Effect
2️⃣ Estimasi dua parameter populasi:
1. Estimasi Proporsi Populasi
2. Estimasi Rata-rata Populasi
3️⃣ Pemilihan parameter penting untuk analisis:
1. Tingkat kepercayaan fleksibel (80% - 99%)
2. Margin of error sesuai kebutuhan pengguna
3. Estimasi proporsi awal atau standar deviasi awal sesuai data pengguna
4️⃣ Penggunaan formula standar:
1. Cochran's Formula (dengan atau tanpa FPC untuk populasi terbatas)
2. Rumus Optimal Neyman untuk Stratified Sampling
3. Perhitungan Design Effect pada Cluster Sampling
5️⃣ Visualisasi hasil:
1. Tampilannya bersih dan interaktif
2. Menampilkan hasil ukuran sampel (n) secara jelas
3. Alokasi sampel per strata otomatis dan mudah dipahami
6️⃣ Fitur edukatif:
1. Menampilkan rumus yang digunakan agar pengguna memahami konsep
2. Menjelaskan secara interaktif kapan menggunakan FPC
3. Membiasakan mahasiswa membaca parameter seperti Z-score, ICC, dan Deff dalam analisis nyata
